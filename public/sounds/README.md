# Custom Sound Assets Folder

You can upload your own custom high-quality sound files into this directory! Since this app runs with an exceptionally smart built-in **Web Audio API sound synthesizer fallback**, the game is already fully functional and makes real sound effects out of the box even without these files.

To override the synthesized sound effects with custom high-fidelity `.mp3` background tracks and sounds, simply upload files with the following exact names to this directory:

1. **`background.mp3`** - Seamless background atmosphere loops playing in the simulation cabin.
2. **`click.mp3`** - Ticks, menu clicks, and subtle cursor selects feedback.
3. **`spin.mp3`** - Rhythmic rolling of the slot reels when pulling the slot lever.
4. **`win.mp3`** - High drama jackpot celebratory tunes.
5. **`lose.mp3`** - Dark, heart-wrenching descending tunes for loss or bankrupt endings.
