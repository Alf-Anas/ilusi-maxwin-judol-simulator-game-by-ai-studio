## 🌟 Tentang Ilusi Maxwin

**Ilusi Maxwin** adalah aplikasi simulator edukasi psikologis interaktif berbasis full-stack (React/Vite + Express + Gemini API) yang khusus dirancang untuk menyimulasikan dinamika destruktif dari judi online (judol) dan jeratan pinjaman online (pinjol). 

Aplikasi ini bertujuan memberikan **Terapi Realitas & Edukasi Psikologis** bagi masyarakat secara interaktif dan aman demi menumbuhkan raba kesadaran batin tanpa harus menanggung kerugian finansial yang asli. Sistem kami merekayasa jebakan dopamin slot (memberikan kemenangan semu di awal permainan sebelum mengunci algoritma ke fase merugi mutlak) yang digabungkan dengan realitas sosial yang menyakitkan.

Aplikasi luar biasa ini dikembangkan menggunakan **Google AI Studio** dan didaftarkan sebagai kontestan dalam ajang kompetisi **JuaraVibeCoding**.

## 🎨 Fitur Utama & Keunggulan

### 1. Sistem Bermain Peran (Roleplay) yang Relevan
Pemain dapat memilih atau membuat karakter khusus:
*   **Pejuang Mahar** (🤵): Mengumpulkan modal nikah instan demi pembuktian diri, menghadapi dinamika hubungan batin yang rapuh dengan tunangannya.
*   **Tulang Punggung** (👨‍👩‍👦): Kepala keluarga yang terjebak utang demi menutupi cicilan rumah dan biaya sekolah anak di tengah tekanan batin.
*   **Karakter Kustom** (👨‍💻): Buat identitasmu sendiri dengan modal, status sosial, dan **Nama Pasangan Riil** untuk mendapatkan efek tamparan realitas asmara secara personal.

### 2. Simulator Slot Interaktif dengan Algoritma Kehancuran (Loss Boost)
*   Visualisasi modern bertenaga **Cyberpunk Neon Vaporwave** dengan efek getar dan putaran dinamis.
*   **Gacor Boost & Loss Logic**: Angka kemenangan diatur beruntung pada putaran-putaran awal (mengaktifkan dopamin) sebelum secara konsisten menguras habis saldo keuangan pemain dan menggiring mereka ke jeratan pinjol kritis.

### 3. Diagnosis Nasib & Evaluasi Tobat (Ditenagai AI Gemini)
*   Berbeda dengan evaluasi game rata-rata, fitur **Diagnosis Nasib** menghadirkan analisis blak-blakan (menampar batin) secara real-time.
*   Menghasilkan evaluasi di 4 pilar utama: *Keuangan*, *Kesehatan Mental*, *Hubungan Sosial (Asmara)*, dan *Rangkuman Tamparan Realitas*.
*   Menganalisis keputusan bermain pemain dan menyebutkan nama pasangannya secara spesifik demi menghadirkan dorongan penyesalan emosional yang mendalam.

### 4. Notifikasi Teror Pinjol & WhatsApp Real-Time
*   Pesan peringatan berkelanjutan dari pacar/istri/keluarga yang kecewa.
*   Teror debt collector yang menuntut pembayaran pinjol berlipat ganda, menstimulasi rasa cemas yang sama dengan korban judol asli.

## 🛠️ Stack Teknologi

Aplikasi ini dibangun menggunakan arsitektur modern berstandar industri:
*   **Sisi Klien (Frontend):** 
    *   **React 19 & Vite** — Rendering antarmuka super cepat dan responsif.
    *   **Tailwind CSS (V4)** — Penataan layout visual berestetika tinggi dan mutakhir.
    *   **Motion (Framer Motion)** — Transisi visual batin dan animasi mikro yang halus.
    *   **Lucide React** — Set ikon UI premium yang seragam.
*   **Sisi Server (Backend):**
    *   **Express JS** — Server backend modular sebagai proxy API aman untuk melindungi API Key.
    *   **Google Gen AI SDK (`@google/genai`)** — Integrasi server-side langsung ke model mutakhir Google Gemini untuk menghasilkan analisis batin naratif yang kuat.
    *   **TypeScript & Node.js** — Tingkat keamanan kode dan penanganan tipe data yang tinggi.

## 🚀 Cara Menjalankan Aplikasi di Lokal

Ikuti langkah-langkah di bawah ini untuk memasang dan menjalankan proyek di komputermu:

### 1. Prasyarat
Pastikan kamu telah menginstal Node.js versi 18+ dan NPM pada sistem operasimu.

### 2. Kloning Repositori
```bash
git clone https://github.com/username/ilusi-maxwin.git
cd ilusi-maxwin
```

### 3. Instalasi Dependensi
```bash
npm install
```

### 4. Konfigurasi Environment Variables (`.env`)
Buat file bernama `.env` di direktori utama, lalu salin struktur dari `.env.example`:
```env
# .env
GEMINI_API_KEY=isi_dengan_gemini_api_key_kamu
```
> *Kamu bisa mendapatkan Gemini SDK API Key secara gratis melalui portal resmi [Google AI Studio](https://aistudio.google.com).*

### 5. Jalankan Mode Pengembangan (Dev Server)
```bash
npm run dev
```
Setelah berjalan, buka browser kesayanganmu dan akses alamat berikut:
👉 [**http://localhost:3000**](http://localhost:3000)
